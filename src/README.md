# Source

Maven sources for VisualCrypto (visual cryptography).

- `main/java/org/leplus/keygen/Main.java` — the entry point.
- `main/java/org/leplus/lib2D/` — 2D geometry primitives (`Point2D`, `Vector2D`,
  `Matrix2D`, `Polygon2D`).
- `main/java/org/leplus/libcrypto/` — cryptographic building blocks (`Mask`, …).

Build with `./mvnw`.
